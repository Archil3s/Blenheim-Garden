# Planting calendar sources

Reviewed 7 November 2026. The UI separates regional guide windows, planned dates
and estimated harvests. Guidance is not a live frost forecast or a promise of
variety-specific maturity.

- Blenheim monthly sowing/establishment windows reuse the existing seasonal
  calendar and historical frost module. Climate context: [NIWA Marlborough](https://niwa.co.nz/climate-and-weather/regional-climatologies/marlborough).
- Seedling harvest estimates for tomato, pumpkin, lettuce, broccoli and basil
  use [Tui’s seedling calendar](https://www.tuigarden.co.nz/media/zjmpldcd/tui-planting-calendar-poster-2025-web.pdf). They require an explicit planned transplant date.
- Nantes carrot maturity is cultivar-specific and measured from planned sowing:
  [Yates Nantes](https://www.yates.co.nz/products/seeds/vegetables/carrot-nantes/).
- The first bean harvest estimate is measured from planned sowing:
  [Yates NZ beans](https://www.yates.co.nz/plants/vegetable/beans/how-to-grow-beans/).

No maturity estimate is inferred from occupancy alone. Perennial/unsupported
crops and unverified varieties can use manual harvest dates. Manual dates
override estimates. Calendar access includes every plan crop; the separate
regional guide contains only supported profiles. No source artwork is copied.

Estimated windows describe first maturity, not the complete picking season. Use
manual harvest dates to plan an extended picking window.
