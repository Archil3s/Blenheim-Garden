# Reference artwork

Original GrowVeg / Growing Interactive artwork retrieved from the public
resources loaded by the user's signed-in planner, at the user's explicit
request to use the exact images. These files are third-party artwork, not
new Blenheim illustrations. See docs/REFERENCE_ASSETS.json for source URLs,
retrieval date and file hashes. Nunito Sans is the reference interface font.

Plant data committed to this change contains names, botanical names, numeric
spacing, classification, companion codes and sprite geometry. It does not
include copied growing-guide prose, account credentials or private garden data.
The 2D footprints are from reference object metadata; 3D heights and procedural
3D models remain local representations.

The original fontello interface icon font was added on 2 November 2026. Source URL, SHA-256 and observed-glyph mapping provenance are recorded in docs/REFERENCE_ASSETS.json.
