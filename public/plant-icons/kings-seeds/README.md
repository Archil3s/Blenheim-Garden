# Kings Seeds web icon assets

This folder contains a web-optimized copy of the 62 plant images prepared for the Blenheim Garden project.

- 8 WebP sprite sheets
- 64 × 64 px cells
- 4 columns × 2 rows per sheet
- 62 mapped plant/variety images total
- `manifest.json` contains the exact sheet, row, column, and pixel position for every image

These are optimized project assets, not the full-resolution master PNG pack. The full-resolution source pack is kept separately so the repository remains lightweight.

The source filename `aggeratum-bouquet-blue` is intentionally preserved as supplied so lookups remain deterministic.
