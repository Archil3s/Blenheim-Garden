# Rasmussen chilli icons — Batch 11 (101–110)

Ten 512 × 512 transparent PNG botanical concepts are stored in `individual_png/`. They correspond to index positions 101–110 in the user-supplied Rasmussen 137-item catalogue (which uses different original sequence numbers, preserved in the manifest).

**Artwork review:** These are original, generated concept illustrations, not official Rasmussen photographs or confirmed perfectly accurate cultivar depictions.

**Planner integration:** Assets only. No code changes or automatic runtime wiring. Existing Kings Seeds and planner icons remain untouched.

Open `index.html` for a lightweight browsable gallery with links to each reference page. See `manifest.json` for relative paths, blob SHAs and status.
