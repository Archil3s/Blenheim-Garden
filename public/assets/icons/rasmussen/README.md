# Rasmussen Gardens botanical chilli icons

This folder distinguishes production-approved assets and **unreviewed botanical concepts**. Each available PNG is a separate image file, not a screenshot of a grid.

- `approved/`: 001–010, existing approved PNG assets.
- `concepts/batch-05/`: 041–050, 10 unreviewed generated PNGs.
- `concepts/batch-06/`: 051–060, 10 unreviewed generated PNGs.
- `concepts/batch-07/`: 061–070, 10 unreviewed generated PNGs.
- `concepts/batch-08/`: 071–080, 10 unreviewed recoloured concept PNGs.
- `asset-manifest.json`: full 137-variety catalogue-to-artwork mapping, with missing images explicitly null.

**Missing individual artwork:** 011–040 and 081–137. Earlier contact-sheet previews and the batch 04 catalogue do not count as completed, verified individual icons. Do not assign a generic asset or recoloured concept to the production planner without visual review and approval.

The files can be pulled by Codex directly from `main`. The manifest is intentionally separate from runtime production wiring; no existing garden planner icon mappings are overwritten.
